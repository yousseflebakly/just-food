# 🍔 Just Food

### Full-Stack Restaurant Ordering & Management Platform

**Just Food** is a full-stack web application designed to provide a modern restaurant ordering experience for customers and a centralized management dashboard for restaurant owners.

Built with **Angular, NestJS, PostgreSQL, and Prisma**, the project focuses on responsive UI, secure authentication, RESTful APIs, and scalable application architecture.

> 🚧 **Project Status: Work in Progress** — Core functionality has been implemented, with additional features and improvements in development.

---

## ✨ Features

### 🛒 Customer Application
- Responsive restaurant website
- Browse products and categories
- Product details and pricing
- Shopping cart with quantity controls
- Customer registration and login
- Authentication-protected checkout
- Order placement and order history
- English and Arabic interface
- Customer profile

### 🛠️ Admin Dashboard
- Admin authentication
- Dashboard with order statistics
- Product management
- Category management
- Order management and status updates
- Restaurant settings
- Product image uploads
